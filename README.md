# Device Chassis

A reference repository that consolidates hardware information for various network device platforms. Each device entry provides:

- **Front & back chassis views** — visual overview of the physical hardware model
- **Airflow direction** — indicates the direction of airflow through the device (front-to-back, back-to-front, or side-to-side)
- **Built-in interfaces** — the physical interfaces that come with the device model out of the box
